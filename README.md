# watch - Video Picture-in-Picture Extension

Keep watching videos while you work, browse, or multitask!

## How to use
- **Hover Button:** Hover over a video and click the button in the top-right corner to instantly enter PiP mode.
- **Keyboard Shortcut:** Quickly toggle the largest playing video into PiP mode by pressing `Alt + P` (`Option + P` for MacOS).
- **Youtube Miniplayers:** It will automatically switch the main video to PiP mode when hover button on bottom-left is clicked and switch to the next video when the current video ends.

## Installation (Developer Mode)
Since this extension is not currently published on the Chrome Web Store, you can load it locally:

1. Open Google Chrome and navigate to `chrome://extensions/`.
2. Enable **"Developer mode"** by toggling the switch in the top right corner.
3. Click the **"Load unpacked"** button in the top left.
4. Select the folder containing this extension.
5. The extension is now installed and ready to use!
